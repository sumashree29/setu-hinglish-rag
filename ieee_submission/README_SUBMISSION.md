# IEEE / ACM Manuscript Submission Package

This directory contains the complete, ready-to-compile LaTeX package for the paper:
**"The Overcorrection Hazard: When Should a Hinglish RAG System Fix the Query?"**

## Included Files
1. `main.tex`: Full IEEE 2-column conference/journal formatted manuscript covering Sections I through VI and Tables I to VI (including Selective Strategies and External Dolly-15k Validation) with verified GroupKFold canonical values.
2. `references.bib`: Complete BibTeX bibliography covering all 23 verified references (no incomplete `and others` placeholders).
3. Figures (`*.png`): `fig1_mrr_vs_cmi.png`, `fig2_outcome_by_termination.png`, `overcorrection.png`, `scaled_corpus_retrieval_comparison_v3.png`.

## 1-Minute Overleaf Instructions
1. Open [Overleaf](https://www.overleaf.com/) and click **New Project** $\to$ **Blank Project**.
2. Upload `main.tex` and `references.bib` into the project root.
3. Click the green **Recompile** button.
4. Download your finalized PDF!
